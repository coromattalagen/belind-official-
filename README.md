# BELIND — WebOus Preview (v1.1)

تشغيل: `npm install` ثم `npm run dev` — للنشر: `npm run build` (المخرجات في dist/).

## الأمان
- CSP + رؤوس الحماية في `index.html` و`public/_headers` (Netlify / Cloudflare Pages). على Vercel/Nginx انقلها إلى إعداد الرؤوس.
- `frame-ancestors` و HSTS لا تعمل إلا كرؤوس HTTP، فلا بد من تفعيل `_headers` على الاستضافة.
- السلة تُعاد بناؤها من بيانات الكتالوج (لا يمكن التلاعب بالأسعار عبر التخزين المحلي).
- تنظيف مدخلات النموذج، حقل فخ للبوتات، رمز طلب عشوائي آمن، أُزيلت الاعتماديات غير المستخدمة (express, genai...).
- شغّل `npm run audit` قبل كل نشر.

## يجب تأكيده مع بلند قبل النشر
الأسعار، حد الشحن المجاني (90$) ورسوم الشحن (8$)، مدد التوصيل، أرقام واتساب، والنوتات العطرية — كلها قيم افتراضية من القالب وليست بيانات مؤكدة.

## الخطوط (نظام طباعة عربي)
- العناوين الكبيرة: Forma DJR Arabic Banner Light — النص: Forma DJR Arabic Deck Light — الأزرار والتسميات والأسعار: Samsung One Arabic Bold — شعار :BELIND: Instrument Serif (OFL).
- الملفات مجزّأة (Subset) للعربية واللاتينية بصيغة WOFF داخل `public/fonts`، بلا أي طلب خارجي (أُزيل Google Fonts من الصفحة والـ CSP).
- **ترخيص:** نسخ Forma المرفقة تجريبية (Testing)، وSamsung One حقوقها محفوظة لسامسونغ. تكفي للمعاينة؛ قبل النشر التجاري على موقع حقيقي اشترِ ترخيص Forma DJR وتحقق من شروط Samsung One، أو بدّلها بخط مرخّص بتغيير أسطر @font-face في `src/index.css`.
- قواعد الطباعة: بلا تباعد أحرف في العربية، ارتفاع سطر 1.9–2 للنص و1.4–1.5 للعناوين، خط العرض (Light) للأحجام الكبيرة فقط، وحبر أغمق مع الخط الخفيف، وعزل اتجاه النص اللاتيني بـ `<bdi dir="ltr">`.
- الهيرو: صورة كاملة بخلفية تتبدل بالفيدينج، وتتلاشى وتتغبّش عند النص (`PerfumeHero.tsx`).

## النشر المجاني على GitHub Pages
1. أنشئ مستودعاً جديداً على github.com (Public — الخطة المجانية لا تدعم Pages في المستودعات الخاصة).
2. ارفع كل محتويات هذا المجلد (Add file ← Upload files)، بما فيها المجلد المخفي `.github`. إن لم يُرفع فأنشئ الملف يدوياً: Add file ← Create new file واكتب `.github/workflows/deploy.yml` والصق محتوى الملف الموجود في الـ ZIP.
3. من Settings ← Pages اجعل Source = **GitHub Actions**.
4. اضغط Actions وانتظر اكتمال التشغيل (دقيقة تقريباً). يظهر الرابط: `https://اسمك.github.io/اسم-المستودع/`.
أي رفع جديد على الفرع `main` ينشر نسخة محدثة تلقائياً. التطبيق يضبط مسار الأصول (`VITE_BASE`) تلقائياً.
ملاحظة: المستودع العام يكشف ملفات الخطوط التجريبية وصور بلند؛ للمعاينة الخاصة استخدم Netlify (رفع مجلد `dist` بالسحب) أو Cloudflare Pages مع مستودع خاص.
